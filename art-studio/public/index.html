Connect the painting engine on your Mac
  1. Install Draw Things (free) from the Mac App Store.
  2. In Draw Things, choose the model FLUX.1 [schnell] and let it download (one time).
  3. Open Draw Things Settings → API Server, switch it on (HTTP, port 7860).
  4. Keep Draw Things open, then press Check again.
